# 📅 2026-05-14 TIL

## 🎯 학습 주제

* 데이터 조회를 위한 다양한 `WHERE` 조건식과 정렬 (`LIKE`, `BETWEEN`, `IN`)
* 여러 테이블의 데이터를 연결하는 다중 `JOIN`과 `SELF JOIN`
* 데이터 그룹화 및 총합계 산출 (`GROUP BY` & `ROLLUP`)

---

## 🧠 핵심 정리

### 1️⃣ 조건 검색과 정렬 (Filtering & Sorting)

원하는 데이터를 세밀하게 필터링하고 원하는 순서대로 나열하는 문법이다.

**주요 조건식 (`WHERE`)**
* `LIKE '%문자%'`: 특정 패턴을 포함하는 문자열 검색 (예: `%2`는 2로 끝나는 데이터)
* `BETWEEN A AND B`: A와 B 사이의 범위 값 조회
* `IN` / `NOT IN`: 여러 값 목록 중 일치하거나 포함되지 않는 데이터 필터링

**정렬과 데이터 제한 (`ORDER BY` & `LIMIT`)**
* `ORDER BY [컬럼] DESC`: 내림차순 정렬 (최신 날짜, 높은 금액 순서 등에 사용)
* `LIMIT n`: 정렬된 결과 중 상위 n개의 행(Row)만 잘라서 출력 (MySQL 기준)

### 2️⃣ 테이블 결합 (JOIN)

관계형 데이터베이스에서 흩어져 있는 두 개 이상의 테이블을 연결하여 하나의 결과로 추출한다.

**JOIN의 종류**
* `INNER JOIN` (기본): 양쪽 테이블 조건이 모두 일치하는 데이터만 출력한다.
* `LEFT JOIN`: 기준(왼쪽) 테이블의 모든 데이터를 유지하고, 우측 테이블에서 일치하는 값만 병합한다. (일치하지 않으면 `NULL` 반환)

**SELF JOIN (셀프 조인)**
* 자기 자신의 테이블을 2개인 것처럼 별칭(`a`, `b`)을 주어 조인하는 기법.
* 한 테이블 내에서 '직원'과 해당 직원의 '관리자' 관계를 매핑할 때 매우 유용하다.

### 3️⃣ 서브쿼리와 그룹화 (Subquery & Grouping)

복잡한 조건을 동적으로 처리하고 데이터를 목적에 맞게 집계하는 방법이다.

**서브쿼리 (Subquery)**
* 쿼리문 안에 포함된 또 다른 쿼리로, 내부 쿼리의 조회 결과를 메인 쿼리의 조건(`WHERE ... IN (...)`)으로 전달할 때 사용한다.


**그룹 집계 및 확장 기능**
* `GROUP BY`: 부서명 등 특정 컬럼을 기준으로 데이터를 묶고, 집계 함수(`COUNT`, `SUM`, `AVG`)를 적용한다.
* `WITH ROLLUP`: 그룹화된 데이터의 항목별 소계 및 '전체 총합계(Grand Total)'를 한 번에 자동 산출해 주는 기능이다.

## ⚙️ 적용

**복합 조건 데이터 추출**: 
* `WHERE`, `ORDER BY`, `LIMIT`을 함께 사용하여 "특정 조건을 만족하면서 가장 최근에 입사한 직원 Top 3"와 같은 필터링 로직 구현
  
**계층형/다중 데이터 매핑**: 
* 직원, 부서, 직급 테이블을 다중으로 `JOIN` 하거나, `SELF JOIN`을 통해 <br> `직원이 속한 부서`와 `해당 직원을 관리하는 관리자의 부서`를 연결하여 조회

**자동 집계 보고서 작성**: 
* `GROUP BY`와 `WITH ROLLUP`을 결합하여, 추가 연산 없이 데이터베이스 쿼리 한 줄로 <br> 부서별 인원 / 급여 평균과 회사 전체 총계를 도출하는 통계 로직 작성
