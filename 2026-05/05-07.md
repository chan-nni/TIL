## 🧠 핵심 정리

### 1️⃣ 다형성 (Polymorphism)

하나의 타입(부모)으로 여러 종류의 객체(자식)를 다루는 객체지향의 핵심 기술이다.

* **업캐스팅 & 다운캐스팅**
  * 업캐스팅: 자식 객체를 부모 타입의 참조 변수에 담는 것 (자동 형변환)
  * 다운캐스팅: 부모 타입 변수를 다시 자식 타입으로 강제 형변환 (`instanceof`로 타입 확인 필수)

* **동적 바인딩 (Dynamic Binding)**
  * 컴파일 시점에는 부모의 메서드를 호출하는 것처럼 보임
  * 런타임 시점에는 참조하는 실제 객체(자식)가 오버라이딩한 메서드가 우선적으로 실행됨

---

### 2️⃣ 추상 클래스 (Abstract Class)

직접 `new` 연산자로 객체를 생성할 수 없는 미완성 설계도이다.

* **구조와 특징**
  * `abstract` 키워드를 사용하여 선언
  * 공통적인 기능(일반 메서드)과 자식이 반드시 구현해야 할 기능(추상 메서드)을 함께 가질 수 있음

* **추상 메서드 (Abstract Method)**
  * 메서드의 몸통(`{}`)이 없는 선언부만 존재하는 메서드
  * 클래스를 상속받는 모든 자식 클래스는 반드시 해당 메서드를 오버라이딩(구현)하도록 강제됨

---

### 3️⃣ 인터페이스 (Interface)

다양한 객체들이 상호작용하기 위해 맞춰야 하는 '표준 규격 및 계약서' 역할을 한다.

* **구현 방식**
  * 상속(`extends`)이 아닌 구현(`implements`)을 사용하며, 다중 구현이 가능
  * 클래스 간의 결합도를 낮춰 유지보수와 부품 교체가 용이한 구조를 만듦

* **인터페이스 구성 요소**
  * 변수: 자동으로 `public static final` 상수가 됨 (공유 규격값)
  * 메서드: 기본적으로 `public abstract` 추상 메서드가 되어 구현을 강제함
  * `default` 메서드: 기존 구현체 수정 없이 새 기능을 추가할 때 사용하는 기본 구현 메서드

---

## ⚙️ 적용

* `instanceof` 연산자를 활용하여 다운캐스팅 전 `ClassCastException` 런타임 에러 방지 로직 적용
* 다형성을 활용하여 `Zookeeper` 클래스의 중복된 `feed(Cat)`, `feed(Tiger)` 메서드를 `feed(Animal)` 하나로 리팩토링
* `IConnectable` 인터페이스를 생성하여 `Mouse`, `Keyboard` 클래스가 동일한 연결 규격을 따르도록 구현
