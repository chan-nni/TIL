## 🧠 핵심 정리

### 1️⃣ JPQL(Java Persistence Query Language)

JPQL은 테이블이 아닌 **엔티티 객체를 대상으로 조회하는 객체지향 쿼리 언어**이다.

기존 SQL

```sql
SELECT menu_name
FROM tbl_menu
WHERE menu_code = 8;
```

JPQL

```java
String jpql = "select m.menuName from Section01Menu m where m.menuCode = 8";
```

JPQL에서는 테이블명이 아닌 엔티티명을 사용한다.

```java
@Entity(name = "Section01Menu")
```

---

### 2️⃣ TypedQuery를 이용한 조회

#### 단일 행, 단일 컬럼 조회

```java
String jpql = "select m.menuName from Section01Menu m where m.menuCode = 8";

TypedQuery<String> query = entityManager.createQuery(jpql, String.class);

String menuName = query.getSingleResult();
```

**getSingleResult()**

* 조회 결과가 하나일 때 사용
* 단일 객체 반환

---

#### 다중 행 조회

```java
String jpql = "select m from Section01Menu m";

TypedQuery<Menu> query = entityManager.createQuery(jpql, Menu.class);

List<Menu> menuList = query.getResultList();
```

**getResultList()**

* 여러 건 조회 시 사용
* List 형태 반환

---

### 3️⃣ DISTINCT 사용

중복 데이터를 제거할 때 사용한다.

```java
String jpql = "select distinct m.categoryCode from Section01Menu m";
```

```java
List<Integer> categoryList =
        entityManager.createQuery(jpql, Integer.class)
                     .getResultList();
```

조회 결과에서 중복된 카테고리 코드가 제거된다.

---

### 4️⃣ IN 연산자 사용

여러 조건을 한 번에 조회할 수 있다.

```java
String jpql = "select m from Section01Menu m where m.categoryCode in (11, 12)";
```

예시

```sql
WHERE category_code IN (11, 12)
```

와 동일한 의미이다.

---

### 5️⃣ LIKE 연산자 사용

특정 문자열이 포함된 데이터를 조회할 수 있다.

```java
String jpql = "select m from Section01Menu m where m.menuName like '%마늘%'";
```

예시 결과

* 마늘치킨
* 마늘빵
* 마늘소스파스타

등 "마늘"이 포함된 메뉴를 조회한다.

---

### 6️⃣ JPQL 파라미터 바인딩

JPQL에서 값이 변경될 수 있는 경우 파라미터를 사용한다.

---

#### 이름 기준 파라미터 바인딩

```java
String jpql = "select m from Section02Menu m where m.menuName = :menuName";
```

```java
List<Menu> menuList =
        entityManager.createQuery(jpql, Menu.class)
                     .setParameter("menuName", menuName)
                     .getResultList();
```

* `:파라미터명` 사용
* 가독성이 좋음

---

#### 위치 기준 파라미터 바인딩

```java
String jpql =
        "select m from Section02Menu m where m.menuName = ?1";
```

```java
List<Menu> menuList =
        entityManager.createQuery(jpql, Menu.class)
                     .setParameter(1, menuName)
                     .getResultList();
```

* 번호를 사용하여 파라미터 지정
* 파라미터가 많아지면 가독성이 떨어짐

---

### 7️⃣ 양방향 연관관계 매핑

#### 연관관계의 주인

```java
@ManyToOne
@JoinColumn(name = "categoryCode")
private Category category;
```

FK를 가진 엔티티가 연관관계의 주인이다.

현재 구조에서는

```text
Menu → Category
```

가 주인이다.

---

#### 연관관계의 주인이 아닌 쪽

```java
@OneToMany(mappedBy = "category")
private List<Menu> menuList;
```

`mappedBy`를 사용하여 주인의 필드명을 지정한다.

```java
mappedBy = "category"
```

는 Menu 엔티티의

```java
private Category category;
```

를 의미한다.

---

### 8️⃣ 지연 로딩(LAZY)

```java
@ManyToOne(
        cascade = CascadeType.PERSIST,
        fetch = FetchType.LAZY
)
private Category category;
```

LAZY 설정 시 실제 연관 객체는 필요할 때 조회된다.

```java
category.getMenuList();
```

호출 시점에 추가 조회가 발생한다.

이를 통해 불필요한 데이터 조회를 줄일 수 있다.
