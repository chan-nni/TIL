## 🧠 핵심 정리

### 1️⃣ EntityManagerFactory와 EntityManager

JPA는 데이터베이스 작업을 수행하기 위해 `EntityManagerFactory`와 `EntityManager`를 사용한다.

**EntityManagerFactory**

* Persistence Unit 설정을 기반으로 생성된다.
* 생성 비용이 크기 때문에 애플리케이션 전체에서 하나만 생성하여 재사용한다.
* 일반적으로 Singleton 패턴으로 관리한다.

```java
private static EntityManagerFactory factory =
        Persistence.createEntityManagerFactory("jpatest");
```

**EntityManager**

* 실제 데이터베이스 작업을 수행하는 객체이다.
* EntityManagerFactory를 통해 생성된다.
* 요청마다 새롭게 생성하여 사용한다.

```java
EntityManager entityManager = factory.createEntityManager();
```

---

### 2️⃣ Persistence Context

Persistence Context는 엔티티를 관리하는 JPA의 메모리 공간이다.

**주요 특징**

* 엔티티의 생명주기를 관리한다.
* 동일한 PK를 조회하면 1차 캐시를 사용한다.
* 데이터 변경 사항을 추적하여 자동으로 반영한다.

JPA는 엔티티를 단순한 객체가 아닌 영속 상태의 객체로 관리한다.

---

### 3️⃣ Entity 조회

`EntityManager.find()`를 사용하면 기본키(PK)를 기준으로 엔티티를 조회할 수 있다.

```java
public Menu findMenuByMenuCode(int menuCode) {

    entityManager = EntityManagerGenerator.getInstance();

    return entityManager.find(Menu.class, menuCode);
}
```

**find() 메서드**

```java
find(엔티티 클래스, PK)
```

* PK를 기준으로 엔티티를 조회한다.
* 조회 결과가 존재하면 엔티티 객체를 반환한다.
* 존재하지 않으면 `null`을 반환한다.

---

### 4️⃣ JPA 엔티티 매핑

엔티티 클래스는 데이터베이스 테이블과 매핑된다.

```java
@Entity(name = "Section02Menu")
@Table(name = "tbl_menu")
public class Menu {
}
```

**주요 어노테이션**

* `@Entity` : 엔티티 클래스 지정
* `@Table` : 매핑할 테이블 지정
* `@Id` : 기본키 지정
* `@Column` : 컬럼 매핑

```java
@Id
@Column(name = "menu_code")
private int menuCode;
```

---

### 5️⃣ JUnit을 활용한 조회 테스트

조회 기능이 정상 동작하는지 테스트 코드를 통해 검증하였다.

```java
@Test
void testFindMenuByMenuCode() {

    int menuCode = 2;

    Menu foundMenu = crud.findMenuByMenuCode(menuCode);

    assertEquals("우럭스무디", foundMenu.getMenuName());
}
```

테스트 코드를 작성하면 기능 구현 후에도 정상 동작 여부를 빠르게 확인할 수 있다.

## ⚙️ 적용

**EntityManagerFactory 싱글톤 관리**

**EntityManager 생성 및 조회**

* EntityManager를 생성하여 PK 기반 엔티티 조회 구현

**JPA 엔티티 매핑**

* 데이터베이스 테이블과 자바 객체를 매핑하여 객체 중심 개발 수행

**JUnit 기반 검증**

* 조회 기능에 대한 테스트 코드를 작성하여 기능 검증 자동화
