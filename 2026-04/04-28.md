## 🧠 핵심 정리

### 1️⃣ Java 아키텍처 구조 (JDK ⊃ JRE ⊃ JVM)

Java는 OS에 종속되지 않는 실행 환경을 제공하며, 그 기반 구조는 다음과 같다.

* **JVM (Java Virtual Machine)**

  → 바이트코드(.class)를 해석하고 실행하는 핵심 엔진
  
  → OS에 맞는 기계어로 변환하여 실행
  
  → JVM은 OS 종속, 애플리케이션은 OS 독립

* **JRE (Java Runtime Environment)**
  
  → Java 애플리케이션 실행을 위한 최소 환경
  
  → 구성: JVM + 표준 라이브러리(Java SE API)
  
  → 실행 환경으로 개발 도구는 포함하지 않음

* **JDK (Java Development Kit)**
  
  → Java 애플리케이션 개발을 위한 전체 도구 집합
  
  → 구성: JRE + 컴파일러(`javac`) 및 개발 도구

---

### 2️⃣ Java 실행 흐름

Java 프로그램은 다음과 같은 단계로 실행된다.

* `.java` 작성
  → `javac` 컴파일
  → `.class` 바이트코드 생성
  → 클래스 로더가 JVM에 로딩
  → JVM이 기계어로 변환 후 실행

* JVM이 중간 계층으로 동작하여 플랫폼 독립성 확보

---

### 3️⃣ 환경 변수 (`JAVA_HOME`)의 역할

IDE 내부 설정만으로 실행은 가능하지만, 시스템 환경 변수는 별도의 목적을 가진다.

* 전역 실행 환경 구성
  → 터미널 및 외부 프로그램에서 Java 실행 경로 참조

* 빌드 도구 호환성
  → Maven, Gradle 등은 `JAVA_HOME`을 기준으로 JDK 탐색 및 사용

* 빌드 및 실행 환경까지 고려할 경우 필수 설정
